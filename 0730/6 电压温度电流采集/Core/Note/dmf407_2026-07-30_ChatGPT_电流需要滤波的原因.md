## 1. 为什么电流特别需要滤波？

电机电流是一个非常"脏"的信号。

比如直流有刷电机：

```
PWM驱动
    |
    ↓
 MOS管高速开关
    |
    ↓
 电机线圈电流
    |
    ↓
 ADC采样
```

电流里面包含：

### ① PWM纹波

假设PWM：

```
高电平:
████
    \
     \
低电平:
     ----
```

电流可能：

```
      /\
     /  \
____/    \____
```

ADC看到的是：

```
2048
2060
2035
2072
2040
```

实际平均电流可能一直是：

2048左右。

---

### ② 电机换向噪声

有刷电机：

- 电刷跳动
- 火花
- 换向瞬间电流突变

会产生尖峰：

```
正常:

----~~~~----

突然:

----~~~~--|^|---~~~~----
```

ADC很容易采到。

---

### ③ MOS管开关干扰

电机驱动板上：

- PWM几十kHz
- 大电流回路
- dv/dt很高

会通过：

- 地线
- 电源
- 空间辐射

进入ADC。

---

所以电流ADC：

```
真实电流:

      1A
----------------

ADC:

0.98
1.03
0.95
1.08
0.91
1.02
```

必须处理。

# 2. 为什么电压不用？

电机供电电压：

例如：

12V电源

经过：

```
12V
 |
分压
 |
ADC
```

一般：

```
12.01V
11.99V
12.02V
```

变化非常慢。

所以不用复杂滤波。

最多：

- DMA取平均
- RC硬件滤波

即可。

---

# 3. 为什么温度不用？

温度变化更慢。

比如：

```
电机温度:

25℃
25.01℃
25.02℃
```

你的ADC：

```
2048
2048
2049
2048
```

根本没必要高频滤波。

# 4. 电流为什么还要测零点？

看这里：

```c
printf("Current:%.1fmA\r\n",
abs(g_adc_val[2]-init_adc_val)*ADC2CURT);
```

重点：

```c
g_adc_val[2]-init_adc_val
```

因为电流采样通常不是：

```
0A = 0V
```

而是：

```
0A = 1.65V
```

比如：

ADC:

```
0A:
2048

1A:
2300

-1A:
1800
```

所以：

```
电流 = 当前ADC - 零电流ADC
```

---

但是这个零点会漂：

例如：

刚上电：

```
2048
```

运行一段时间：

```
2060
```

原因：

- 运放温漂
- 参考电压变化
- PCB温升

所以启动时：

```c
init_adc_val
```

就是找：

> 当前没有电机运行时，ADC对应的0A值。

# 5. 这个滤波写法其实有问题

这里：

```c
init_adc_val += g_adc_val[2];
init_adc_val /= 2;
```

不是平均1000次。

它类似：

```
新值 = (旧值 + 当前值) / 2
```

叫：

**一阶低通滤波 / 指数平均**

例如：

第一次：

```
(2048+2050)/2=2049
```

第二次：

```
(2049+2052)/2=2050
```

越往后旧数据权重越来越小。

更标准写法：

```c
init_adc_val = 0;

for(t=0;t<1000;t++)
{
    init_adc_val += g_adc_val[2];
    delay_ms(1);
}

init_adc_val /= 1000;
```

这才是真正平均1000次。

# 6. 电机控制里面电流滤波甚至比电压重要

因为电流通常用于：

- 过流保护
- 转矩估计
- 电流环控制(FOC)
- 堵转检测

如果没有滤波：

比如保护：

```
if(current > 5A)
    stop_motor();
```

噪声尖峰：

```
4A
4.2A
5.5A(瞬间)
4A
```

可能导致误保护。

---

所以总结：

|信号|滤波需求|原因|
|-|-|-|
|电流|★★★★★|PWM、电机噪声、保护需求|
|电压|★★|变化慢|
|温度|★|变化极慢|

电机开发里，**电流采样是ADC里面最难处理的一类**，这也是为什么FOC里面电流采样位置、采样时刻、滤波算法都非常讲究。你这个正点原子例程其实已经是在模拟真实电机控制里的电流采样流程。

电压**不是完全不会波动**，而是相对于电流来说，它受到的干扰小很多，而且变化速度慢，所以通常不需要像电流一样滤波。

核心原因是：**电压测量点和电流测量点的位置不同。**

---

## 1. 电流是在"干扰源"附近测的

电机电流路径：

```
电源
 |
 MOS管
 |
 电机线圈
 |
 电流采样电阻
 |
 GND
```

电流采样通常放在：

- MOS管附近
- 电机回路里面
- 大电流路径上

这里正是噪声最大的地方。

比如PWM：

```
PWM开:

12V ─────
      |
      | 电流突然增加
      ↓
    电机

PWM关:

0V ─────
```

电流：

```
0.5A
1.2A
0.6A
1.3A
```

变化非常快。

---

## 2. 电压测量一般测的是稳定电源

比如你的代码：

```c
printf("Valtage:%.1fV\r\n",
       g_adc_val[0]*ADC2VBUS);
```

测的是母线电压：

```
12V电源
 |
 |
 +---- ADC电压采样
 |
 MOS管
 |
 电机
```

ADC看到：

```
12.00V
11.98V
12.01V
11.99V
```

因为：

- 电源有大电容
- 分压电阻隔离
- 电源内阻较低

所以变化很小。

---

## 3. 一个直观区别

假设电机PWM：

```
PWM频率 20kHz
```

每50us开关一次。

电流：

```
     /\      /\
    /  \    /  \
___/    \__/    \___
```

每几十微秒变化。

但是电压：

```
12V -----------------
      小纹波
12V ~~~~~~~~~~~~~~~~
```

只有几百Hz甚至更低的变化。

---

## 4. 为什么电压不会跟着PWM跳？

因为电机驱动板有：

### 电源电容

例如：

```
12V
 |
 +----||----
 |
 MOS
```

电容提供瞬间电流。

PWM打开：

```
电容 → 电机
```

PWM关闭：

```
电源 → 给电容充电
```

所以母线电压比较稳定。

---

## 5. 但是电压也会滤波

实际工业产品里：

电压ADC也经常：

### 硬件滤波

例如：

```
12V
 |
 R
 |
 +---- ADC
 |
 C
 |
GND
```

形成RC低通。

或者软件：

```c
voltage = (voltage_old * 7 + adc_new) / 8;
```

只是要求没有电流那么高。

---

## 6. 为什么电机控制更关注电流？

因为：

### 电压决定输入条件

比如：

```
12V → 12V
```

变化一点没关系。

### 电流决定电机状态

电机：

```
转矩 ≈ 电流
```

所以：

- 堵转 → 电流暴涨
- 负载增加 → 电流增加
- 电机异常 → 电流异常

因此电流必须准确。

---

所以总结：

| |电压|电流|
|-|-|-|
|变化速度|慢|快|
|噪声来源|少|多|
|采样位置|电源侧|电机回路|
|PWM影响|小|巨大|
|滤波需求|低|高|

简单理解：

**电压像看水箱水位，变化慢；电流像看水管流量，水泵一开一关马上变化。**  
电机系统里真正难测的是电流。
