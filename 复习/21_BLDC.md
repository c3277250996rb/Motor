# 🏷️ 第21章 直流无刷电机

### 1. 什么是直流无刷电机（BLDC）

面试回答：

> BLDC 是一种没有电刷和换向器的直流电机，通过电子换向控制定子绕组电流方向，使产生旋转磁场，从而驱动永磁转子旋转。

核心区别：

|          | 有刷电机   | BLDC     |
| -------- | ---------- | -------- |
| 转子     | 线圈绕组   | 永磁体   |
| 定子     | 永磁体     | 三相绕组 |
| 换向方式 | 机械换向器 | 电子换向 |
| 寿命     | 短         | 长       |
| 控制     | 简单       | 复杂     |

---

### 2. BLDC 为什么需要换向？

这是面试高频。

因为：

- 定子线圈通电产生磁场
- 永磁转子受到磁力作用旋转
- 如果磁场固定，转子只能转到一个稳定位置
- 必须不断改变定子磁场方向，让转子持续追随

所以：

> BLDC 的本质就是不断改变三相绕组电流方向，产生旋转磁场。

---

### 3. BLDC 三相绕组结构

BLDC 通常：

- 三相绕组：
  - U相
  - V相
  - W相

一般采用：

> 星形连接

三个绕组一端内部连接，另外三端引出。

文档描述：

> 无刷电机绕组通常是3组，并且只有3个引出接线端子，一般为星形接法。  
> 

---

### 4. BLDC 与 PMSM 区别（重点）

这个非常容易被问。

文档核心：

|          | BLDC     | PMSM         |
| -------- | -------- | ------------ |
| 反电动势 | 梯形波   | 正弦波       |
| 电流     | 梯形波   | 正弦波       |
| 绕组     | 集中绕组 | 分布绕组     |
| 控制     | 六步换向 | FOC          |
| 导通方式 | 两两导通 | 三相同时导通 |

面试回答：

> BLDC 主要采用120°六步换向控制，电流接近梯形波；PMSM反电动势接近正弦波，因此通常采用FOC控制，使三相电流保持正弦。

---

### 5. BLDC 六步换向原理 

这是本章核心。

BLDC 有三相：

```
U
V
W
```

每次：

- 一相接正
- 一相接负
- 一相悬空

例如：

```
U+   V空   W-
```

电流：

```
U → W
```

产生磁场方向。

##### 换向对照切换表:

| 步骤 | U    | V    | W    |
| ---- | ---- | ---- | ---- |
| 1    | +    | 空   | -    |
| 2    | +    | -    | 空   |
| 3    | 空   | -    | +    |
| 4    | -    | 空   | +    |
| 5    | -    | +    | 空   |
| 6    | 空   | +    | -    |

循环后形成旋转磁场。

总结：

> BLDC 的运行方式为绕组两两导通，所以三相线圈的导通组合只有6种，根据合理顺序切换即可让转子跟着磁场旋转。

### 6. 三相逆变桥 

这是连接 STM32 和 BLDC 的关键。

因为 MCU 输出：

```
GPIO/PWM
```

不能直接驱动电机。

所以需要：

```
STM32
 |
PWM
 |
三相逆变器
 |
UVW绕组
 |
BLDC
```

##### 三相逆变器：

![image-20260823164359729](./assets/image-20260823164359729.png)

三个：

- U桥
- V桥
- W桥

作用：

控制每一相：

- 接正极
- 接负极
- 高阻态

文档：

> 三相逆变电路就是由三个半桥构成，每个半桥控制对应的一相绕组。  

---

### 7. BLDC 为什么需要霍尔传感器？

因为换向需要知道转子位置。

霍尔作用：

检测：

- 转子位置
- 换向时刻

三路霍尔：

```
Hall_U
Hall_V
Hall_W
```

三个信号组合：

有6种有效状态。

对应六步换向。

文档：

> 霍尔传感器的3相电平输出主要用于指示无刷电机转子的位置。  

---

### 8. BLDC 调速原理 

不是直接改变电压，而是 PWM。

原因：

电机平均电压：

$$
U_{avg}=D\times U_{dc}
$$

改变占空比：

↓

改变绕组平均电压

↓

改变电流

↓

改变转矩

↓

改变速度

文档：

> 工作时一般使用PWM代替高低电平，控制线圈电流，从而控制转子扭矩及转速。  

---

### 9. BLDC 参数

⚫ **极对数：**转子磁铁 NS 级的对数，此参数和电机旋转速度有关：电子速度 = 电机实际速 度 * 极对数。

⚫ **KV 值：**电机的运转速度，值越大电机转速越大。电机转速 = KV 值 * 工作电压。同系 列同外形尺寸的无刷电机，根据绕线匝数的多少，会表现出不同的 KV 特性。绕线匝 数多的， KV 值低，最高输出电流小，扭力大；绕线匝数少的， KV 值高，最高输出 电流大，扭力小；

 ⚫ **额定转速：**额定的电流下的空载转速，通常单位用 RPM 表示； 

⚫ **转矩：**电机中转子产生的可以带动机械负载的驱动力矩。通常单位为：N.M；
