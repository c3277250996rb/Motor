# 🏷️ 第21章 直流无刷电机

### 1. 什么是直流无刷电机（BLDC）

面试回答：

> BLDC 是一种没有电刷和换向器的直流电机，通过电子换向控制定子绕组电流方向，使产生旋转磁场，从而驱动永磁转子旋转。

核心区别：

|          | 有刷电机   | BLDC     |
| -------- | ---------- | -------- |
| 转子     | 线圈绕组   | 永磁体   |
| 定子     | 永磁体     | 三相绕组 |
| 换向方式 | 机械换向器 | 电子换向 |
| 寿命     | 短         | 长       |
| 控制     | 简单       | 复杂     |

---

### 2. BLDC 为什么需要换向？

这是面试高频。

因为：

- 定子线圈通电产生磁场
- 永磁转子受到磁力作用旋转
- 如果磁场固定，转子只能转到一个稳定位置
- 必须不断改变定子磁场方向，让转子持续追随

所以：

> BLDC 的本质就是不断改变三相绕组电流方向，产生旋转磁场。

---

### 3. BLDC 三相绕组结构

BLDC 通常：

- 三相绕组：
  - U相
  - V相
  - W相

一般采用：

> 星形连接

三个绕组一端内部连接，另外三端引出。

文档描述：

> 无刷电机绕组通常是3组，并且只有3个引出接线端子，一般为星形接法。  
> 

---

### 4. BLDC 与 PMSM 区别（重点）

这个非常容易被问。

文档核心：

|          | BLDC     | PMSM         |
| -------- | -------- | ------------ |
| 反电动势 | 梯形波   | 正弦波       |
| 电流     | 梯形波   | 正弦波       |
| 绕组     | 集中绕组 | 分布绕组     |
| 控制     | 六步换向 | FOC          |
| 导通方式 | 两两导通 | 三相同时导通 |

面试回答：

> BLDC 主要采用120°六步换向控制，电流接近梯形波；PMSM反电动势接近正弦波，因此通常采用FOC控制，使三相电流保持正弦。

---

### 5. BLDC 六步换向原理 

这是本章核心。

BLDC 有三相：

```
U
V
W
```

每次：

- 一相接正
- 一相接负
- 一相悬空

例如：

```
U+   V空   W-
```

电流：

```
U → W
```

产生磁场方向。

##### 换向对照切换表:

| 步骤 | U    | V    | W    |
| ---- | ---- | ---- | ---- |
| 1    | +    | 空   | -    |
| 2    | +    | -    | 空   |
| 3    | 空   | -    | +    |
| 4    | -    | 空   | +    |
| 5    | -    | +    | 空   |
| 6    | 空   | +    | -    |

循环后形成旋转磁场。

总结：

> BLDC 的运行方式为绕组两两导通，所以三相线圈的导通组合只有6种，根据合理顺序切换即可让转子跟着磁场旋转。

### 6. 三相逆变桥 

这是连接 STM32 和 BLDC 的关键。

因为 MCU 输出：

```
GPIO/PWM
```

不能直接驱动电机。

所以需要：

```
STM32
 |
PWM
 |
三相逆变器
 |
UVW绕组
 |
BLDC
```

##### 三相逆变器：

![image-20260823164359729](./assets/image-20260823164359729.png)

三个：

- U桥
- V桥
- W桥

作用：

控制每一相：

- 接正极
- 接负极
- 高阻态

文档：

> 三相逆变电路就是由三个半桥构成，每个半桥控制对应的一相绕组。  

---

### 7. BLDC 为什么需要霍尔传感器？

因为换向需要知道转子位置。

霍尔作用：

检测：

- 转子位置
- 换向时刻

三路霍尔：

```
Hall_U
Hall_V
Hall_W
```

三个信号组合：

有6种有效状态。

对应六步换向。

文档：

> 霍尔传感器的3相电平输出主要用于指示无刷电机转子的位置。  

---

### 8. BLDC 调速原理 

不是直接改变电压，而是 PWM。

原因：

电机平均电压：

$$
U_{avg}=D\times U_{dc}
$$

改变占空比：

↓

改变绕组平均电压

↓

改变电流

↓

改变转矩

↓

改变速度

文档：

> 工作时一般使用PWM代替高低电平，控制线圈电流，从而控制转子扭矩及转速。  

---

### 9. BLDC 参数

⚫ **极对数：**转子磁铁 NS 级的对数，此参数和电机旋转速度有关：电子速度 = 电机实际速 度 * 极对数。

⚫ **KV 值：**电机的运转速度，值越大电机转速越大。电机转速 = KV 值 * 工作电压。同系 列同外形尺寸的无刷电机，根据绕线匝数的多少，会表现出不同的 KV 特性。绕线匝 数多的， KV 值低，最高输出电流小，扭力大；绕线匝数少的， KV 值高，最高输出 电流大，扭力小；

 ⚫ **额定转速：**额定的电流下的空载转速，通常单位用 RPM 表示； 

⚫ **转矩：**电机中转子产生的可以带动机械负载的驱动力矩。通常单位为：N.M；

# 🏷️ 第22章：有感方波驱动--新增面试知识点

这一章其实不是再教你一个全新的电机原理，而是把前面第21章学的：

所以这一章最重要的是理解**“软件到底怎么根据霍尔状态控制六个MOS管”**。

---

## 一、最核心：霍尔状态 → 六步换相

这是本章最值得面试准备的知识点。

前面第21章你已经知道：

- BLDC 三相绕组：U、V、W
- 三个霍尔传感器：U、V、W
- 三个霍尔信号组合起来有 **6种有效状态**
- 每个状态对应一个固定的上下桥臂导通组合
- 霍尔状态变化 → 判断转子位置 → 切换MOS管 → 实现换相

例如文档中的正转表：

| 霍尔状态 | 导通   |
| -------- | ------ |
| 101      | U+、V- |
| 001      | U+、W- |
| 011      | V+、W- |
| 010      | V+、U- |
| 110      | W+、U- |
| 100      | W+、V- |

这张表你**非常值得记住逻辑，而不是死背表格**。

核心就是：

> **霍尔传感器负责“告诉我转子在哪”，六步换相表负责“告诉我现在应该开哪两个MOS”。**

文档明确说明，霍尔三个输出组合后可以判断当前转子具体位置，并且仍然满足六步一周期。`403_PDFsam_DMF407电机控制专题教程_V1.0_第 21 章 直流无刷电机.pdf`

---

# 二、为什么是6种有效霍尔状态？

三个霍尔传感器，每个只有：

> 0 / 1

所以理论上有：

$$
2^3=8
$$

种组合。

但是 BLDC 六步换相中：

> **只有6种状态是有效的。**

剩下：

$$
000
$$

和

$$
111
$$

属于无效状态。

所以面试很容易问：

> **三个霍尔传感器为什么能确定六个换相区间？**

回答：

> 三个霍尔传感器形成3位二进制状态，理论上有8种组合，其中000和111为无效状态，因此剩下6种有效状态，每种状态对应一个电气区间和一组固定的上下桥臂导通关系。

这个回答已经比较像面试了。

---

# 三、为什么霍尔状态变化就要换相？

这个是面试官非常喜欢追问的“为什么”。

整个逻辑：

**转子转动**

↓

**霍尔状态变化**

↓

**检测到新的转子位置**

↓

**查六步换相表**

↓

**改变三相逆变桥MOS管导通组合**

↓

**产生新的定子磁场方向**

↓

**继续拉着永磁转子转动**

所以：

> **霍尔传感器本质上不是直接控制电机，而是在提供转子位置信息。**

真正负责输出功率的是：

> **三相逆变桥。**

这一点要和“霍尔控制电机”区分开。

---

# 四、三相逆变桥到底怎么控制BLDC？

前面你已经学过三相逆变桥，这一章开始真正把它用起来。

三相：

- U
- V
- W

每一相都有：

- 上桥臂
- 下桥臂

所以一共：

$$
3\times2=6
$$

个MOS管。

例如：

> U+ 导通，V- 导通，W相悬空

那么电流路径就是：

$$
V_{DC}\rightarrow U相绕组\rightarrow V相绕组\rightarrow GND
$$

于是：

- U相接正
- V相接负
- W相悬空

这就是六步换相中的一种状态。

---

# 五、为什么永远只有“两相导通，一相悬空”？

这是BLDC六步方波控制的核心特点。

例如：

> U+ + V-

那么：

- U：接正
- V：接负
- W：悬空

所以任意时刻：

> **两相导通，一相不导通。**

文档前面明确给出了这一运行方式：BLDC采用绕组两两导通的方式，因此三相线圈只有6种有效导通组合。`403_PDFsam_DMF407电机控制专题教程_V1.0_第 21 章 直流无刷电机.pdf`

这也是为什么你后面学习**反电动势过零检测**时，会专门检测那一条“悬空相”。

---

# 六、PWM到底加在哪里？

这一章一个非常重要的工程知识就是：

**六步换相决定“方向”，PWM决定“力度”。**

可以把它理解成：

### 换相

决定：

> 电流从哪一相流向哪一相。

### PWM

决定：

> 这个电流到底有多大。

所以：

> **换相负责控制磁场方向，PWM负责控制电机的转矩/速度。**

文档中也明确说明，直接把电源加在线圈上会导致电机快速升速，因此实际工作时使用PWM代替高低电平，以控制线圈电流，从而控制转子扭矩和转速。`403_PDFsam_DMF407电机控制专题教程_V1.0_第 21 章 直流无刷电机.pdf`

---

# 七、为什么PWM能够控制速度？

这个你面试时最好不要只回答：

> “因为PWM占空比改变了。”

最好继续说：

$$
D\uparrow
$$

↓

平均施加到绕组上的电压增大

↓

绕组电流能力增大

↓

产生的电磁转矩增大

↓

电机转速发生变化

所以更准确地说：

> **PWM通过改变绕组上的平均电压/电流，进而改变电磁转矩，使电机达到不同的转速。**

---

# 八、霍尔传感器代码实际上在干什么？

这一章代码里有一个非常典型的操作：

把三个霍尔GPIO读取结果组合成一个三位状态。

例如：

```c
State |= 0x01U;
State |= 0x02U;
State |= 0x04U;
```

最终得到：

$$
State = H_3H_2H_1
$$

也就是说：

- Hall1 → 最低位
- Hall2 → 中间位
- Hall3 → 最高位

文档明确说明了这一点。`403_PDFsam_DMF407电机控制专题教程_V1.0_第 21 章 直流无刷电机.pdf`

因此面试如果问：

> **“你的BLDC代码怎么根据霍尔信号实现换相？”**

你可以直接说：

> 我先读取三个霍尔GPIO，将三个霍尔状态组合成一个3位状态值，然后根据这个状态查六步换相表，确定当前应该导通哪一个上桥臂和哪一个下桥臂，再通过PWM控制导通桥臂的占空比。

这句话非常适合背。

# 九、电机启动和停止为什么不能只关闭PWM？

这是本章代码里一个比较有价值的工程细节。

文档中的 `stop_motor1()` 做了多件事情：

1. 关闭驱动芯片输出
2. 停止三个PWM通道
3. 将三个CCR清零
4. 将低侧IO全部关闭
5. 最终让上下桥臂全部关断

而启动时则：

1. 使能驱动芯片
2. 开启TIM1三个PWM通道

文档明确展示了这个启停逻辑。`403_PDFsam_DMF407电机控制专题教程_V1.0_第 21 章 直流无刷电机.pdf`

所以面试可以问：

> **“为什么电机停止时不只是把PWM占空比设置为0？”**

从这份代码的设计来看，更稳妥的回答是：

> 停止电机不仅要让PWM停止，还需要关闭驱动器输出并确保上下桥臂全部关断，从硬件层面保证功率器件处于安全状态。

# 十一、这章还有一个特别值得你掌握的“代码思想”

六步换相函数本质上就是：

```text
读取霍尔
   ↓
得到Hall状态
   ↓
switch(Hall状态)
   ↓
选择六种换相状态之一
   ↓
设置三个CCR
   ↓
设置三个低侧GPIO
   ↓
完成换相
```

也就是说，**BLDC六步控制并不是什么特别神秘的算法**。

它本质上就是：

> **状态机 + PWM。**

这是一个非常适合面试的说法。
