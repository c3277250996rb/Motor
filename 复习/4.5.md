# 🏷️ 4.5.1 DAC简介

### 1. DAC是什么？和ADC区别

- ADC用于采集外部模拟信号
- DAC用于根据数字量生成模拟电压
- ADC是输入，DAC是输出

---

### 2. STM32F407 DAC主要特点

重点：

##### 12位DAC

STM32F407 DAC分辨率：

```
12bit
```

意味着：

```
0~4095
```

共：

$$
2^{12}=4096
$$

例如：

参考电压：

$$
V_{REF}=3.3V
$$

数字量：

$$
Data=2048
$$

输出：

$$
V_{out}
=
\frac{Data}{4095}\times V_{REF}
$$

约：

$$
V_{out}=1.65V
$$

面试可能问：

> DAC分辨率是什么意思？

答：

表示DAC能够将满量程电压分成多少份，12bit表示4096个等级。

---

### 3. DAC输出电压范围

重点：

DAC不能输出负电压。

只能：

```
0V ~ VREF+
```

所以如果生成正弦波：

原本：

$$
y=A\sin(x)
$$

有负半周期。

需要整体上移：

$$
y=A\sin(x)+A
$$

变成：

```
0 ~ 2A
```

这也是后面DAC输出正弦波为什么需要偏置。

---

### 4. DAC输出缓冲(Buffer)

##### Buffer加入后

加入运放：

```
              Buffer


DAC ----->  +-------+
            | 运放  |
            +-------+
                |
                |
             输出
```

作用：

降低输出阻抗，提高带载能力。

|            | 开启Buffer | 关闭Buffer |
| ---------- | ---------- | ---------- |
| 输出阻抗   | 低         | 高         |
| 驱动能力   | 强         | 弱         |
| 带负载能力 | 好         | 差         |
| 输出精度   | 略有影响   | 更高       |
| 适合       | 外部使用   | 内部采样   |

---

### 5. DAC触发方式

DAC更新数据有三种方式：

##### 软件触发

CPU直接写：

```
HAL_DAC_SetValue()
```

流程：

```
CPU
 |
写DAC寄存器
 |
DAC输出
```

优点：

简单

缺点：

CPU参与

---

##### 定时器触发

例如：

TIM6产生更新事件：

```
TIM6
 |
TRGO
 |
DAC
 |
输出
```

优点：

输出周期稳定。

---

##### DMA触发

完整链路：

```
CPU配置一次
 |
 | RAM数组
 ↓
TIM6
 |
 | 更新事件 TRGO
 ↓
DMA请求
 |
 | 搬一个数据
 ↓
DAC
 |
 ↓
输出电压
```

# 🏷️ 4.5.2 DAC输出

### 1. DAC初始化流程

面试可以回答：

DAC初始化步骤：

##### ① 开启DAC时钟

例如：

```
__HAL_RCC_DAC_CLK_ENABLE()
```

---

##### ② GPIO设置模拟模式

DAC引脚不能普通GPIO输出。

例如：

PA4：

```
GPIO_MODE_ANALOG
```

---

##### ③ 初始化DAC

调用：

```
HAL_DAC_Init()
```

---

##### ④ 配置DAC通道

例如：

```
HAL_DAC_ConfigChannel()
```

配置：

- 通道
- 触发方式
- 输出buffer

---

##### ⑤ 开启DAC

```
HAL_DAC_Start()
```

---

### 2. DAC和ADC联合测试思想

实验里面：

DAC输出：

```
PA4
 |
连接
 |
ADC采集
```

流程：

```
CPU设置DAC值

      ↓

DAC输出电压

      ↓

ADC采集

      ↓

验证DAC输出是否正确
```

这个思想面试很喜欢问：

> 如何验证DAC输出？

答：

可以使用示波器直接观察，也可以使用ADC采样反馈验证。

---

### 3. DAC在电机控制中的用途（重要）

虽然这两节只是基础，但是结合后面FOC非常有价值。

实际电机控制：

DAC常用于调试内部变量。

例如：

FOC里面：

```
Id
Iq
角度
电流
速度
```

这些变量本来存在MCU内部。

可以：

```
变量
 |
DAC
 |
模拟电压
 |
示波器
```

观察波形。

例如：

输出：

$$
I_q
$$

可以直接看到转矩电流变化。
