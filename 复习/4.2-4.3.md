# 🏷️ 4.2 基本定时器

### 1. 定时器中断的核心机制（必问）

- **时基单元三要素**：`PSC`（预分频器）、`ARR`（自动重载寄存器）、`CNT`（计数器）。

- **溢出时间计算公式**（面试高频）：
  $$
  T_{out} = \frac{(ARR + 1) \times (PSC + 1)}{T_{clk}}
  $$

  - 能说清楚每个变量的含义和单位。
  - 能举例：170MHz 时钟，`PSC=16999`，`ARR=4999`，溢出时间 = 500ms。

------

### 2. 更新事件（Update Event）的产生方式

- **硬件产生**：`CNT == ARR` 时溢出。
- **软件产生**：置位 `UG` 位（`TIMx_EGR` 寄存器）。
- **中断触发条件**：`UIE` 位使能（`TIMx_DIER` 的 bit 0）。

------

### 3. 中断处理流程（HAL 库视角）

- **初始化流程**：
  1. 使能时钟（`__HAL_RCC_TIMx_CLK_ENABLE()`）
  2. 填充 `TIM_HandleTypeDef`
  3. 调用 `HAL_TIM_Base_Init()`
  4. 调用 `HAL_TIM_Base_Start_IT()`
- **中断回调**：
  - `HAL_TIM_IRQHandler()` → 调用 `HAL_TIM_PeriodElapsedCallback()`
- **面试常问**：
  - 为什么要清除中断标志位？
  - 回调函数里为什么要判断 `Instance`？

# 🏷️ 4.3.2 高级定时器中断

## 1、高级定时器（TIM1/8） vs 基本定时器（TIM6/7）的核心差异（必问）

| 对比项          | 基本定时器（TIM6/7） | 高级定时器（TIM1/8/20）     |
| :-------------- | :------------------- | :-------------------------- |
| 计数模式        | 仅递增               | 递增、递减、中心对齐        |
| 重复计数器      | 无                   | 有（RCR）                   |
| 互补输出 / 死区 | 无                   | 有                          |
| 刹车功能        | 无                   | 有                          |
| 编码器接口      | 无                   | 有                          |
| 时钟源          | 仅内部               | 内部 / 外部引脚 / ETR / ITR |

## 2、通用定时器 (TIM 2~5 )

**通用定时器 = 基本定时器（时基单元） + 输入捕获 + 输出比较（PWM）**
**高级定时器 = 通用定时器 + 互补输出 + 死区控制 + 刹车功能 + 重复计数器**

## 3、高级定时器的计数模式（新增概念）

- **三种模式**：
  1. **递增计数**（同基本定时器）
  2. **递减计数**
  3. **中心对齐模式**（向上计数到 ARR 溢出，再向下计数到 0 溢出）
- **更新事件发生条件**（面试重点）：
  - 递增：`CNT == ARR`
  - 递减：`CNT == 0`
  - 中心对齐：在 ARR 和 0 两个位置都产生更新事件

> **面试常问**：中心对齐模式适合什么场景？
> **答**：适合需要对称 PWM 或对相位要求较高的电机控制场景。

## 4、重复计数器（RCR）—— 高级定时器独有

- **作用**：不是每次溢出都产生更新事件，而是每 `RCR + 1` 次溢出才产生一次更新事件。
- **寄存器**：`TIMx_RCR`（16 位，有影子寄存器）
- **典型应用**：输出指定个数 PWM（4.3.8 会深入）

> **面试常问**：RCR = 3 时，几个溢出周期产生一次更新事件？
> **答**：4 次。

- **PWM 生成机制**：计数器 `CNT` 与捕获/比较寄存器 `CCR` 比较，决定输出高低电平。

- **关键公式**（面试手撕）：

  - **频率**：

  - **占空比**：
    $$
    Duty = \frac{高电平时间} {ARR + 1}
    $$
    

- **面试追问**：ARR 和 CCR 分别决定什么？（ARR 决定周期/频率，CCR 决定占空比）

### 2. PWM 模式 1 vs 模式 2（高频考点）

| 模式       | 有效电平行为               | 典型用途          |
| :--------- | :------------------------- | :---------------- |
| PWM 模式 1 | `CNT < CCR` 时输出有效电平 | 常用，便于理解    |
| PWM 模式 2 | `CNT < CCR` 时输出无效电平 | 与模式 1 极性相反 |

- **面试常问**：这两种模式本质区别是什么？（有效电平定义相反，配合极性位可实现相同波形）

### 3. 输出极性与有效电平（容易混淆）

- **`OCPolarity`**（输出极性）：
  - `HIGH`：CCR 比较匹配时输出高电平
  - `LOW`：CCR 比较匹配时输出低电平
- **面试陷阱**：改变极性会影响占空比的定义，但**实际波形占空比由 CCR/ARR 和极性共同决定**。

### 4. 不同配置下的高电平时间

| 配置           | 高电平时间  | 软件占空比公式          |
| :------------- | :---------- | :---------------------- |
| 模式1 + 极性高 | CCR         | CCR / (ARR+1)           |
| 模式1 + 极性低 | ARR+1 - CCR | (ARR+1 - CCR) / (ARR+1) |
| 模式2 + 极性高 | ARR+1 - CCR | (ARR+1 - CCR) / (ARR+1) |
| 模式2 + 极性低 | CCR         | CCR / (ARR+1)           |

你会发现：**模式1 + 极性高 = 模式2 + 极性低**（波形完全一样）

# 🏷️ **4.3.4 高级定时器互补输出带死区刹车控制**

## 1、核心概念理解（必问）

1. 什么是互补输出（Complementary Output）？

- **定义**：同一通道的两路输出（OCx 和 OCxN），电平**始终相反**（一路高，另一路低）。
- **应用场景**：驱动 H 桥的上下桥臂。

2. 为什么需要死区时间（Dead Time）？

- **根本原因**：功率器件（MOSFET/IGBT）存在**开关延迟**，关断比导通慢。
- **后果**：如果互补信号直接切换，上下桥臂会**同时导通** → 短路 → 烧毁器件。
- **解决方法**：插入一段**两者都为无效电平**的时间（死区），让上管完全关断后再打开下管。

# 🏷️ **4.3.5 高级定时器输入捕获**

## 1、输入捕获的核心原理（必问）

1. 输入捕获能做什么？

- 测量**电平脉宽**、**PWM周期**、**频率**、**占空比**。

2. 测量高电平脉宽的原理（面试高频）

- **步骤**：
  1. 设置通道为**上升沿捕获**，捕获到上升沿时：
     - 记录当前 `CNT` 值（被锁存入 `CCRx`）
     - 清零 `CNT`
     - 切换为**下降沿捕获**
  2. 捕获到下降沿时：
     - 再次读取 `CCRx`（此时值为高电平期间计数值）
  3. 高电平时间 = `CCR值 × 计数周期`

3. 计数周期 = 1 / (定时器时钟 / (PSC+1))

## 2、中断处理与溢出管理（面试核心难点）

1. 需要两个中断

- **捕获中断**（`TIMx_CC_IRQHandler`）：处理边沿事件
- **更新中断**（`TIMx_UP_IRQHandler`）：处理定时器溢出（防止长脉宽测量错误）

## 3、典型计算题（面试手撕）

**场景**：定时器时钟 = 170MHz，PSC = 169，ARR = 0xFFFF，计数频率 = 1MHz（1μs 计数一次），测量到一个高电平脉宽，捕获到 `CCR = 25000`，溢出次数为 2 次。

**问**：高电平时间是多少？

**答**：

- 总计数值 = `2 × (0xFFFF + 1) + 25000 = 2 × 65536 + 25000 = 156072`
- 高电平时间 = `156072 × 1μs = 156.072ms`

## 4、常见追问（考察工程经验）

| 问题                                | 考察点                                   |
| :---------------------------------- | :--------------------------------------- |
| 输入捕获能测的最大脉宽是多少？      | 是否考虑 ARR 和溢出次数上限              |
| 如果被测信号频率很高，怎么处理？    | 提高计数频率 / 降低 PSC                  |
| 输入捕获和 PWM 输入模式有什么区别？ | PWM 输入是捕获的特例，自动测周期和占空比 |
| 为什么捕获前要清零 CNT？            | 保证计数值从 0 开始，便于直接读数        |

# 🏷️ 4.3.6 高级定时器 PWM 输入

### 1. PWM 输入模式的核心原理（必问）

**面试官常问**：PWM 输入模式和普通输入捕获有什么区别？

- **本质**：PWM 输入模式是**输入捕获的特例**，它**同时使用两个捕获通道**（IC1 和 IC2）来测量一个 PWM 信号。
- **分工**：
  - **IC1** 测量周期（通常捕获上升沿）
  - **IC2** 测量高电平宽度（通常捕获下降沿）
- **关键公式**（面试高频）：
  - PWM 周期 = `(CCR1 + 1) × 计数周期`
  - PWM 占空比 = `(CCR2 + 1) / (CCR1 + 1)`

### 2. 从模式（Slave Mode）——复位模式（必问）

**面试官常问**：为什么要使用复位模式？不使能行不行？

- **复位模式作用**：当检测到选定触发信号（如 TI1FP1 上升沿）时，**计数器自动清零**。
- **为什么必须用**：保证每个 PWM 周期都是从 0 开始计数，否则周期测量会累计误差。

### 3. 触发信号选择（TRGI）的配置（必问）

- **触发源**：必须选择 `TI1FP1` 或 `TI2FP2`（只能从 CH1 或 CH2 输入）。
- **配置位**：`TIMx_SMCR` 的 `TS[4:0] = 00101`（TI1FP1）。
- **面试常问**：为什么不能用 CH3 或 CH4 做 PWM 输入？
  → 因为硬件上只有 TI1FP1 和 TI2FP2 能作为触发输入（TRGI）。
- **TRGI的概念**：触发输入（TRGI）是定时器从模式的控制入口，它决定了计数器何时复位、启动或停止。在 PWM 输入模式中，TRGI 选择了 TI1FP1，用于在每个 PWM 周期开始时硬件复位计数器，从而实现周期和高电平宽度的同步捕获。

### 4. 两个捕获通道的映射关系（易混淆，但常考）

| 通道 | 映射目标   | 捕获边沿 | 作用                   |
| :--- | :--------- | :------- | :--------------------- |
| IC1  | 映射到 TI1 | 上升沿   | 测量周期 → 存入 CCR1   |
| IC2  | 映射到 TI1 | 下降沿   | 测量高电平 → 存入 CCR2 |

**关键点**：IC1 和 IC2 **都映射到同一个输入引脚（TI1）**，但捕获边沿不同。

### 5. 测量范围与精度（工程思维考察）

- **测量精度** = 计数器时钟周期（如 1μs）。
- **最大周期** = `ARR + 1` × 计数周期（本实验为 65536μs）。
- **测量超出上限的 PWM 的三种方案**: 

| 方案                       | 做法                                                         | 优缺点                                                 |
| :------------------------- | :----------------------------------------------------------- | :----------------------------------------------------- |
| **方案一：降低计数频率**   | 增大 PSC，比如从 170 改为 17000，计数周期从 1μs 变为 100μs，65536 × 100μs = 6.5s，足够测 1Hz | ✅ 简单 ❌ 精度下降（从 1μs 降到 100μs）                 |
| **方案二：用 32 位定时器** | 使用 TIM2/TIM5，ARR 可达 2³²-1，直接覆盖 1Hz 甚至更低        | ✅ 精度不变 ❌ 硬件资源受限                              |
| **方案三：溢出中断补偿**   | 保持 16 位定时器，在溢出中断里累加溢出次数                   | ✅ 精度不变 ✅ 不换硬件 ❌ 软件逻辑复杂，需要处理中断竞争 |

### 9. 容易混淆的概念（面试避坑）

| 术语       | 含义                                           |
| :--------- | :--------------------------------------------- |
| **TRGI**   | 定时器内部触发输入信号（从模式控制器的输入）   |

# 🏷️ 4.3.7 高级定时器输出比较模式

### 1：输出比较模式的“翻转”功能（核心）

**这是什么？**
在输出比较模式下，定时器的计数器的值（CNT）会与捕获/比较寄存器（CCRx）的值不断比较。

- 当CNT == CCRx时，**输出电平（OCx）会发生翻转**（高变低或低变高）。

**用翻转功能如何产生PWM？**

- **原理**：`ARR`（自动重载值）决定PWM的周期，而PWM的占空比被**固定为50%**。
- **关键**：修改`CCRx`的值，改变的是**PWM波的相位**（即上升沿/下降沿在周期内的位置），而不是占空比。
- **公式**：PWM周期 `T = 2 * (ARR + 1) * (PSC + 1) / Tclk` （因为有两次翻转才完成一个周期）。

### 2：相位控制（新增概念）

**这是什么？**
通过设置不同的`CCRx`值，可以让各个通道输出的PWM波的上升沿出现在周期中的不同位置。

- 例：`ARR = 999`。
  - `CCR1 = 250` → 翻转点在25%位置。
  - `CCR2 = 500` → 翻转点在50%位置。
  - `CCR3 = 750` → 翻转点在75%位置。
    因此，得到的三个PWM波频率相同、占空比相同（50%），但**相位不同**。

**面试可能这样问：**
**“在输出比较翻转模式下，如何实现三路相位不同的PWM波？”**

- 参考答案：保持`ARR`值相同（决定相同周期和50%占空比），然后为三个通道设置不同的`CCR`值（如250、500、750），这三个值决定了翻转点的时间，从而产生不同的初始相位。

### **3:  输出比较模式产生的PWM，和PWM模式产生的PWM，主要区别是**

- **核心区别**：PWM模式可以灵活调节频率（ARR）和占空比（CCR），而**输出比较翻转模式产生的PWM占空比固定为50%**，主要用于调节相位。输出比较模式更侧重于“在特定时刻执行动作（如翻转、输出高/低电平）”，而PWM模式是专为生成方波设计的。

# **🏷️ 4.3.8 高级定时器输出指定个数PWM**

### 1. 如何实现“输出指定个数PWM”？

- **核心思路**：利用**重复计数器（RCR）**，当定时器发生 `RCR + 1` 次上溢/下溢时，才产生一次更新事件。
- 步骤：
  1. 设置 `RCR = N - 1`，表示输出 N 个 PWM 脉冲；
  2. 在更新中断中关闭定时器或停止输出；
  3. 若需连续输出多个 N，需在中断中重新装载 RCR。

### 2. 重复计数器（RCR）的作用

- 只有**高级定时器（TIM1/TIM8）** 才有 RCR；
- RCR 是 8 位寄存器（0~255），因此**单次最多输出 256 个脉冲**；
- 若要输出更多脉冲，需在中断中分批设置 RCR。

### 3. 如何实现输出超过 256 个脉冲？

- 在更新中断中判断剩余脉冲数：
  - 若剩余 > 256，设置 RCR = 255，继续输出；
  - 若剩余 < 256，设置 RCR = 剩余数 - 1；
  - 若剩余为 0，关闭定时器。

### 4. 为什么要在中断中关闭定时器？

- 因为 RCR 是 8 位，无法一次输出大量脉冲；
- 关闭定时器可避免多余脉冲输出，保证精度。
