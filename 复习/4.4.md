# 🏷️ 4.4.2 单通道ADC采集

### 1. ADC 基本概念（必问）

| 问题                           | 回答要点                                  |
| :----------------------------- | :---------------------------------------- |
| **什么是ADC？**                | 模数转换器，将模拟电压信号转换为数字量。  |
| **STM32F407 ADC 是多少位的？** | 12 位逐次逼近型，分辨率 2¹² = 4096 级。   |
| **ADC 输入电压范围？**         | 0 ~ 3.3V（由 VREF+ 和 VREF- 决定）。      |
| **ADC 时钟频率限制？**         | 最大 36MHz，例程中为 21MHz（84MHz / 4）。 |

------

### 2. ADC 工作模式（高频考点）

#### 第一层：流程控制模式（你已掌握的4种）

这是HAL库初始化结构体`ADC_InitTypeDef`里配置的，确实是你学的那4种：

| 模式         | 作用                               |
| :----------- | :--------------------------------- |
| **单次转换** | 触发一次，转一次就停（本实验用的） |
| **连续转换** | 触发一次，一直转，像流水线         |
| **扫描模式** | 按顺序把多个通道轮流转一遍         |
| **间断模式** | 把“扫描”打散，分批次触发           |

> **面试陷阱**：很多人以为“扫描模式”必须和“连续模式”绑定，**其实不是**。扫描模式可以和单次搭配（扫完一轮停），也可以和连续搭配（扫完一轮立刻重新扫）。

------

#### 第二层：触发源模式（面试必问，电机控制核心）

这决定了ADC**什么时候开始转换**，在电机控制中，**必须用定时器触发**，否则电流采样会乱套。

| 触发方式         | 说明                         | 电机控制中的应用                                 |
| :--------------- | :--------------------------- | :----------------------------------------------- |
| **软件触发**     | 代码写 `SWSTART=1` 启动      | 仅用于调试、简单电压采集                         |
| **定时器触发**   | 由TIM1/TIM8的TRGO信号触发ADC | **FOC电流采样必须用这种方式**，与PWM中心对齐同步 |
| **外部引脚触发** | 由EXTI引脚边沿触发           | 用于外部事件同步采样                             |

> **面试金句**：*“在电机控制中，我通常使用定时器触发ADC，以确保电流采样点与PWM载波周期对齐，避免开关噪声干扰。”*——这句话会立刻提升技术深度。

------

#### 第三层：多ADC协同模式（进阶/高级岗位会问）

STM32F407有3个ADC，它们可以组合工作，这是你当前章节还没学到的（在4.4.1简介里提过“双重模式”）。

| 模式              | 说明                            | 用途                                                         |
| :---------------- | :------------------------------ | :----------------------------------------------------------- |
| **独立模式**      | 各ADC各干各的                   | 一般场合                                                     |
| **双重/三重模式** | 多个ADC同步采样，交替或同时转换 | **FOC双电阻/三电阻采样**，需要同时采集两相或三相电流，必须用双重模式 |

------

#### 面试高频追问 & 避坑指南

| 追问                                           | 正确回答                                                     |
| :--------------------------------------------- | :----------------------------------------------------------- |
| *“你用的ADC是12位，怎么做到更高精度？”*        | 过采样 + 求平均 + DMA搬运（你4.4.3会学到）                   |
| *“单次转换和连续转换，哪种适合电机电流采样？”* | **单次转换 + 定时器触发**。连续转换会导致采样点乱飘，无法与PWM同步。 |
| *“扫描模式能搭配间断模式吗？”*                 | 可以。扫描+间断 = 每次触发只扫一部分通道，适合低优先级通道的轮询。 |

### 3. 转换时间计算（面试常考计算题）

公式：

```
Tconv = 采样时间 + 逐次逼近时间
```



- 采样时间可选：3 ~ 480 个 ADC 时钟周期
- 逐次逼近时间 = 12 个周期（12 位模式）

**例程计算**：

- ADC 时钟 = 21MHz
- 采样时间 = 480 周期
- Tconv = (480 + 12) / 21MHz ≈ **23.4 µs**

### 4. ADC 转换流程（HAL 库步骤）

1. 使能 ADC 和 GPIO 时钟
2. 配置 GPIO 为模拟输入模式
3. 初始化 ADC（分辨率、对齐、扫描模式等）
4. 配置 ADC 通道（通道号、采样时间、转换顺序）
5. 启动 ADC（软件或外部触发）
6. 等待转换完成（查询 EOC）
7. 读取 ADC_DR 寄存器

------

### 5. HAL 库关键函数（面试可能问“你用到了哪些函数”）

| 函数                          | 作用                     |
| :---------------------------- | :----------------------- |
| `HAL_ADC_Init()`              | 初始化 ADC 工作参数      |
| `HAL_ADC_ConfigChannel()`     | 配置通道、采样时间、顺序 |
| `HAL_ADC_Start()`             | 启动 ADC 转换            |
| `HAL_ADC_PollForConversion()` | 等待转换完成（轮询）     |
| `HAL_ADC_GetValue()`          | 读取转换结果             |

------

### 6. 电压换算公式（必会）

```
电压值 = (ADC_DR 值 / 4096) * 3.3V
```



> 例：ADC 读数为 2048 → 电压 = 1.65V

------

### 7. 电机控制中的 ADC 应用（加分回答）

| 应用场景     | 说明                       |
| :----------- | :------------------------- |
| **电流采样** | 采集相电流（通过采样电阻） |
| **电压检测** | 母线电压、电池电压         |
| **温度检测** | NTC 热敏电阻分压采样       |
| **位置反馈** | 电位器或霍尔传感器模拟量   |

> 可强调：ADC 采样时间、触发同步（与 PWM 对齐）在电机控制中至关重要。

------

### 8. 面试追问点（准备更深）

- **如何提高 ADC 精度？**
  → 多次采样取平均、硬件滤波、参考电压稳定、使用 DMA 防止数据覆盖。
- **DMA 在 ADC 中的作用？**
  → 自动搬运数据，避免 CPU 频繁读取，适合多通道或高速采样。
- **什么是 ADC 注入组？**
  → 可打断规则组转换，用于紧急高优先级采样（如过流保护）。
