# 🏷️ 4.4.2 单通道ADC采集

### 1. ADC 基本概念（必问）

| 问题                           | 回答要点                                  |
| :----------------------------- | :---------------------------------------- |
| **什么是ADC？**                | 模数转换器，将模拟电压信号转换为数字量。  |
| **STM32F407 ADC 是多少位的？** | 12 位逐次逼近型，分辨率 2¹² = 4096 级。   |
| **ADC 输入电压范围？**         | 0 ~ 3.3V（由 VREF+ 和 VREF- 决定）。      |
| **ADC 时钟频率限制？**         | 最大 36MHz，例程中为 21MHz（84MHz / 4）。 |

------

### 2. ADC 工作模式（高频考点）

#### 第一层：流程控制模式（你已掌握的4种）

这是HAL库初始化结构体`ADC_InitTypeDef`里配置的，确实是你学的那4种：

| 模式         | 作用                               |
| :----------- | :--------------------------------- |
| **单次转换** | 触发一次，转一次就停（本实验用的） |
| **连续转换** | 触发一次，一直转，像流水线         |
| **扫描模式** | 按顺序把多个通道轮流转一遍         |
| **间断模式** | 把“扫描”打散，分批次触发           |

> **面试陷阱**：很多人以为“扫描模式”必须和“连续模式”绑定，**其实不是**。扫描模式可以和单次搭配（扫完一轮停），也可以和连续搭配（扫完一轮立刻重新扫）。

------

#### 第二层：触发源模式（面试必问，电机控制核心）

这决定了ADC**什么时候开始转换**，在电机控制中，**必须用定时器触发**，否则电流采样会乱套。

| 触发方式         | 说明                         | 电机控制中的应用                                 |
| :--------------- | :--------------------------- | :----------------------------------------------- |
| **软件触发**     | 代码写 `SWSTART=1` 启动      | 仅用于调试、简单电压采集                         |
| **定时器触发**   | 由TIM1/TIM8的TRGO信号触发ADC | **FOC电流采样必须用这种方式**，与PWM中心对齐同步 |
| **外部引脚触发** | 由EXTI引脚边沿触发           | 用于外部事件同步采样                             |

> **面试金句**：*“在电机控制中，我通常使用定时器触发ADC，以确保电流采样点与PWM载波周期对齐，避免开关噪声干扰。”*——这句话会立刻提升技术深度。

------

#### 第三层：多ADC协同模式（进阶/高级岗位会问）

STM32F407有3个ADC，它们可以组合工作，这是你当前章节还没学到的（在4.4.1简介里提过“双重模式”）。

| 模式              | 说明                            | 用途                                                         |
| :---------------- | :------------------------------ | :----------------------------------------------------------- |
| **独立模式**      | 各ADC各干各的                   | 一般场合                                                     |
| **双重/三重模式** | 多个ADC同步采样，交替或同时转换 | **FOC双电阻/三电阻采样**，需要同时采集两相或三相电流，必须用双重模式 |

------

#### 面试高频追问 & 避坑指南

| 追问                                           | 正确回答                                                     |
| :--------------------------------------------- | :----------------------------------------------------------- |
| *“你用的ADC是12位，怎么做到更高精度？”*        | 过采样 + 求平均 + DMA搬运（你4.4.3会学到）                   |
| *“单次转换和连续转换，哪种适合电机电流采样？”* | **单次转换 + 定时器触发**。连续转换会导致采样点乱飘，无法与PWM同步。 |
| *“扫描模式能搭配间断模式吗？”*                 | 可以。扫描+间断 = 每次触发只扫一部分通道，适合低优先级通道的轮询。 |

### 3. 转换时间计算（面试常考计算题）

公式：

```
Tconv = 采样时间 + 逐次逼近时间
```



- 采样时间可选：3 ~ 480 个 ADC 时钟周期
- 逐次逼近时间 = 12 个周期（12 位模式）

**例程计算**：

- ADC 时钟 = 21MHz
- 采样时间 = 480 周期
- Tconv = (480 + 12) / 21MHz ≈ **23.4 µs**

### 4. ADC 转换流程（HAL 库步骤）

1. 使能 ADC 和 GPIO 时钟
2. 配置 GPIO 为模拟输入模式
3. 初始化 ADC（分辨率、对齐、扫描模式等）
4. 配置 ADC 通道（通道号、采样时间、转换顺序）
5. 启动 ADC（软件或外部触发）
6. 等待转换完成（查询 EOC）
7. 读取 ADC_DR 寄存器

------

### 5. HAL 库关键函数（面试可能问“你用到了哪些函数”）

| 函数                          | 作用                     |
| :---------------------------- | :----------------------- |
| `HAL_ADC_Init()`              | 初始化 ADC 工作参数      |
| `HAL_ADC_ConfigChannel()`     | 配置通道、采样时间、顺序 |
| `HAL_ADC_Start()`             | 启动 ADC 转换            |
| `HAL_ADC_PollForConversion()` | 等待转换完成（轮询）     |
| `HAL_ADC_GetValue()`          | 读取转换结果             |

------

### 6. 电压换算公式（必会）

```
电压值 = (ADC_DR 值 / 4096) * 3.3V
```



> 例：ADC 读数为 2048 → 电压 = 1.65V

------

### 7. 电机控制中的 ADC 应用（加分回答）

| 应用场景     | 说明                       |
| :----------- | :------------------------- |
| **电流采样** | 采集相电流（通过采样电阻） |
| **电压检测** | 母线电压、电池电压         |
| **温度检测** | NTC 热敏电阻分压采样       |
| **位置反馈** | 电位器或霍尔传感器模拟量   |

> 可强调：ADC 采样时间、触发同步（与 PWM 对齐）在电机控制中至关重要。

------

### 8. 面试追问点（准备更深）

- **如何提高 ADC 精度？**
  → 多次采样取平均、硬件滤波、参考电压稳定、使用 DMA 防止数据覆盖。
- **DMA 在 ADC 中的作用？**
  → 自动搬运数据，避免 CPU 频繁读取，适合多通道或高速采样。
- **什么是 ADC 注入组？**
  → 可打断规则组转换，用于紧急高优先级采样（如过流保护）。

# 🏷️ **4.4.3 单通道ADC采集（DMA读取）**

> **在电机控制中，ADC 需要高频采样电流和电压，配合 DMA 可以极大减轻 CPU 负担，保证控制算法实时性。**

### 1. **为什么要用 DMA 来读取 ADC 数据？**

- **不用 DMA**：CPU 必须轮询或等待 ADC 转换完成，再读取数据，浪费 CPU 资源。
- **用 DMA**：ADC 转换完成后自动将数据搬运到内存，CPU 可以同时处理其他任务，**提高系统实时性**，尤其在**多通道、高速采样**场景下必不可少。

> 💡 面试加分句：
> 在电机控制中，电流采样通常需要高频（如 10kHz~50kHz），如果用 CPU 轮询，会严重影响 FOC 算法执行，所以必须用 DMA。

------

### 2.  **ADC 连续转换模式 vs 单次转换模式，什么时候用哪个？**

| 模式     | 特点                 | 适用场景                             |
| :------- | :------------------- | :----------------------------------- |
| 单次转换 | 触发一次，转换一次   | 低功耗、间歇采样                     |
| 连续转换 | 转换完自动开始下一次 | 高频连续采样（如电流、电压闭环控制） |

> 本实验用的是 **连续转换 + DMA**，适合**实时性要求高**的场景。

------

### 3. **ADC + DMA 的配置顺序是什么？（面试常问）**

标准顺序如下：

1. 使能 ADC、DMA、GPIO 时钟
2. 配置 GPIO 为模拟输入模式
3. 初始化 DMA（外设地址、内存地址、数据长度、传输方向、增量模式等）
4. 初始化 ADC（分辨率、对齐、扫描模式、连续模式、触发方式）
5. 配置 ADC 通道（通道号、采样时间、规则序列）
6. 用 `HAL_LINKDMA` 将 ADC 句柄与 DMA 句柄关联
7. 启动 DMA 中断（`HAL_DMA_Start_IT`）
8. 启动 ADC DMA 传输（`HAL_ADC_Start_DMA`）

------

### 4. **DMA 传输完成如何判断？两种常见方式**

- **方式一（中断）**：在 DMA 中断服务函数中判断标志位（如 `TCIF`），置位标志变量。
- **方式二（回调）**：使用 HAL 库的 `HAL_ADC_ConvCpltCallback` 回调函数（本实验未用，但面试常问）。

> 本实验用的是 **直接判断中断标志位 + 软件置标志**，效率更高。

------

### 5. **ADC 数据对齐方式**

**右对齐是默认推荐，因为读取后直接得到 0~4095 的 ADC 计数值，适合大多数场景。**

**左对齐主要用于定点数运算或需要保留高精度中间结果的情况，比如某些 DSP 滤波器或定点 FOC 算法中，左移 4 位可以让整数部分更大，减少定点乘法的精度损失。另外在一些 8 位处理器上，左对齐还可以直接取高字节做粗略测量，省去移位操作。**



# 🏷️ 4.4.4 多通道 ADC 采集（DMA 读取）

------

### 1. ADC扫描模式（最大新增点）★★★★★

4.4.3：

单通道：

```
ADC_CH3
 ↓
ADC_DR
 ↓
DMA
 ↓
buffer
```

4.4.4：

多个通道：

```
ADC_CH3
 ↓
ADC_CH4
 ↓
ADC_CH5
 ↓
ADC_DR
 ↓
DMA
 ↓
buffer[0]
buffer[1]
buffer[2]
```

文档重点：

> 本实验使用规则组多通道的连续转换模式，通过软件触发启动。

------

### 2. ADC规则序列寄存器 ADC_SQRx ★★★★★

这是4.4.4真正新增的寄存器知识。

单通道：

只需要：

```
ADC_SQR3
SQ1 = 通道号
```

例如：

```
SQ1 = ADC_CH3
```

多通道：

需要配置转换顺序：

例如：

```
SQ1 = CH3
SQ2 = CH4
SQ3 = CH5
```

文档：

> 使用3个通道同时采集，SQ1、SQ2、SQ3分别对应输入通道3、4、5。

面试可能问：

> ADC多个通道如何确定转换顺序？

回答：

> 通过ADC规则序列寄存器ADC_SQR1~SQR3配置，每个SQ位对应一次转换的通道。

------

### 3. DMA数组对应多个ADC结果 ★★★★

4.4.3：

例如：

```c
uint16_t adc_value;
```

只有一个值。

4.4.4：

变成：

```c
uint16_t adc_value[3];
```

对应：

```
adc_value[0] → CH3
adc_value[1] → CH4
adc_value[2] → CH5
```

------

### 4. 为什么多通道必须用DMA ★★★★

这个其实4.4.3已经提过，但4.4.4进一步体现。

因为：

ADC只有一个：

```
ADC_DR
```

多个通道：

```
CH3转换
 ↓
ADC_DR

CH4转换
 ↓
ADC_DR覆盖

CH5转换
 ↓
ADC_DR覆盖
```

如果CPU读取不及时，前面的数据丢失。

所以：

```
ADC_DR
 ↓
DMA
 ↓
数组
```

文档也说明：

> 多通道转换时，上一个通道转换的数据会被下一个通道覆盖，所以需要及时取走，常用DMA模式。
